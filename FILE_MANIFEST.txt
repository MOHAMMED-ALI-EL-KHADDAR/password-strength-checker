ALGORITHMS IMPLEMENTED
═══════════════════════════════════════════════════════════════════════════════

1. Shannon Entropy
   Formula: H = -Σ(p_i × log₂(p_i))
   Purpose: Measures password randomness
   Range: 0-5.5 bits (typical passwords)
   Complexity: O(n) where n = password length

2. Complexity Scoring
   Formula: min(length/2, 20) + count(types) × 7.5
   Range: 0-50 points
   Factors: Length + character type diversity
   Complexity: O(n) for regex scans

3. Pattern Detection (zxcvbn)
   Detects: Dictionary words, keyboard patterns, sequences, repeats
   Score: 0-4 (0=very weak, 4=very strong)
   Output: Feedback, suggestions, crack time estimates
   Complexity: O(n²) pattern matching

4. k-Anonymity Protocol
   Step 1: Hash password locally with SHA-1
   Step 2: Send first 5 hex characters to API
   Step 3: API returns passwords with matching prefix
   Step 4: Compare full hash locally (client-side)
   Privacy: 20-bit equivalent (1,048,576 possible prefixes)

Entropy Scale:
  < 2.0 bits   → Very weak (highly predictable)
  2.0-3.5 bits → Weak (easy patterns)
  3.5-4.5 bits → Good entropy
  > 4.5 bits   → Excellent entropy

Complexity Score:
  0-10 points   → Very Weak
  11-20 points  → Weak
  21-35 points  → Fair
  36-45 points  → Good
  46-50 points  → Excellent

zxcvbn Score:
  0 → Very Weak (guessable in seconds)
  1 → Weak (minutes to hours)
  2 → Fair (days to years)
  3 → Strong (years to centuries)
  4 → Very Strong (centuries or never)
